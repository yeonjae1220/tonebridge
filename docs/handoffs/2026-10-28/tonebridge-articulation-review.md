# ToneBridge 제안 재검토와 다국어 발음 학습 설계

검토일: 2026-10-27 · 사용자 선택: 여러 언어를 지원하는 공통 구조

이 문서는 [앞선 제품·UI 검토](tonebridge-product-review.md)를 보완한다. 코드에서 확인한 사실, 문헌의 결과, 제안하는 제품 가설을 구분했다. 제품 코드는 변경하지 않았다. 로그인 후 사용 흐름은 코드 기준이며 실사용 계정의 녹음·학습 효과를 측정한 결과는 아니다.

## 1. 핵심 판단

자동 저장과 정리는 유지하되, 제품의 가치를 **“내가 실제로 말한 내용에 대해, 무엇을 어떻게 바꿀지 이해하고, 다시 말해 변화를 확인하는 경험”**으로 구체화하는 것이 좋다.

혀·치아·입술·턱의 위치와 움직임을 설명하는 조음 안내는 이 경험에 잘 맞는다. 다만 모든 녹음에 해부학 설명을 붙이지 않는다. 현재 학습 목표에 도움이 되는 한 가지 단서를 골라 보여주고, 설명 없이도 새 문장에서 사용할 수 있는지 확인한다. 저장·분류·다음 연습 선택은 자동화하고, 듣기·회상·말하기는 학습자가 수행하도록 설계한다.

친구에게 구체적인 설명을 듣고 좋아진 경험은 중요한 제품 가설의 출발점이다. 효과의 원인이 조음 설명인지, 개인화된 피드백인지, 반복 연습인지 분리해서 검증해야 한다.

## 2. 앞선 제안에서 수정할 점

| 앞선 방향 | 재검토 결과 | 수정 제안 |
|---|---|---|
| 개인 학습장을 제품의 중심으로 전환 | 현재 스터디 우선 구조와 맞지만, 사용자 조사 없이 제품 전략을 확정하기에는 이르다 | 친구의 설명이 개인 연습으로 남는 연결을 먼저 검증한다. 커뮤니티를 단순 부가 기능으로 축소할지는 사용 결과로 결정한다 |
| 기록하면 자동으로 학습 카드 생성 | 기록량이 늘수록 복습 부담도 증가할 수 있다 | 원본 기록과 연습 항목을 구분한다. 반복된 어려움·사용자 목표·전달에 미치는 영향을 기준으로 소수만 추천한다 |
| 선택·클릭 최소화 | 학습에 필요한 선택까지 없애면 수동 재생 소비가 된다 | 제목·폴더·저장 조작을 줄이고, 듣고 구분하기·다시 말하기·힌트 없이 말하기는 남긴다 |
| 간격 반복 복습 | 문장 회상만으로 발음의 습득을 설명하기 어렵다 | 소리 구별, 안내를 보며 발음, 새 문장에 적용하는 능력을 따로 본다. 1·3·7일 같은 간격은 초기 실험값이다 |
| 음성 자동 분석·알림 | 기존 텍스트 AI와 결과 화면 SSE만으로 가능한 기능이 아니다 | 음성 평가와 알림은 별도 검증 대상이다. 분석 불가·미지원 상태에서도 저장·재생·친구 피드백이 작동하게 한다 |
| 다양한 학습 지표 | 숫자가 많아도 다음 행동을 알려주지 못할 수 있다 | 첫 화면은 “다음에 바꿀 한 가지”와 해당 음성 구간. 점수는 평가 근거가 있을 때만 보조로 표시한다 |

자동 저장은 개인 기록 저장을 뜻한다. 커뮤니티 공개, 친구 전송, 크레딧 차감까지 자동으로 확장하지 않는다. “기기에 저장됨 / 서버 저장 완료 / 분석 중 / 분석 불가”를 구분해야 사용자가 저장 여부를 계속 확인하지 않아도 된다.

## 3. 조음 설명의 학습 근거와 한계

**명시적인 발음 설명과 연습을 결합할 근거가 있다.** Saito의 연구는 일본어 모어 영어 학습자 49명을 대상으로 영어 /ɹ/를 다뤘다. 조음 설명과 강조된 발음 예시를 추가한 집단은 설명을 추가하지 않은 집단보다 더 큰 개선을 보였고, 학습하지 않은 어휘로의 일반화도 나타났다. 다만 설명·예시·연습의 결합 결과이며, 특정 그림이나 모든 언어에서 같은 효과를 입증한 것은 아니다. [저자 공개 논문, 학술지 게재 2013·온라인 선공개 2012](https://kazuyasaito.net/SSLA2013.pdf)

**시각 자료를 더하는 것이 항상 우수하지는 않다.** Chang(2023)의 영어 모음 대조 학습에서는 초음파 피드백 집단과 음성만 사용한 집단 모두 개선됐지만, 집단 간 향상 차이는 유의하지 않았다. 이는 해당 연구에서 추가 이득을 확인하지 못했다는 뜻이며, 두 방식의 효과가 언제나 같다는 증명은 아니다. [ASHA 학술지 초록](https://pubs.asha.org/doi/10.1044/2023_JSLHR-22-00587)

**과제와 언어 범위의 제약도 있다.** 일본어 모어 학습자 21명을 대상으로 한 연구에서는 초음파 피드백의 이점이 이야기 읽기에는 나타났지만 단어 목록 과제에는 나타나지 않았다. [Bryfonski 외, 2023, 출판사 초록](https://benjamins.com/catalog/jslp.22051.bry)

2025년 체계적 문헌고찰은 31개 연구를 검토했으며 영어 중심 편중과 다양한 실험 조건을 지적했다. 추가 이득은 학습자와 목표 소리에 따라 달라질 수 있다. 또 서로 다른 조음 방식이 비슷한 음향 결과를 만들 수 있으므로, 마이크 녹음만 듣고 사용자의 정확한 혀 위치를 관찰한 것처럼 설명하면 안 된다. [Aalto 외, 2025, 초록·공개 본문 일부](https://doi.org/10.1016/j.specom.2025.103324)

제품에 대한 해석: 실제 학습자의 혀를 측정하는 초음파 피드백과, 모델 발음을 설명하는 애니메이션은 서로 다른 개입이다. 전자의 연구 효과를 앱의 그림에 그대로 적용하지 않는다. 그림은 “이 소리를 만드는 방법의 예시”로 표시하고, 실제 학습 효과는 별도로 확인한다.

자료 공개와 앱 내 재사용 허용은 별개다. Seeing Speech는 CC BY-NC-ND 4.0이며 AI 학습·머신러닝·자동 변환에는 사전 서면 동의를 요구한다고 명시한다. 따라서 당장은 외부 참고 링크로 다루고, 앱 내 자산은 별도 허락을 받거나 전문가 검수로 독립 제작하는 편이 적절하다. [공식 이용 안내](https://www.seeingspeech.ac.uk/)

IPA 공식 차트는 출처 표시와 동일조건변경허락을 전제로 상업적 재사용도 허용하는 CC BY-SA 4.0이다. 이는 해당 차트 및 파생물의 조건이며 다른 기관의 영상에 적용되지 않는다. Iowa·Sejong·OJAD의 앱 내 복제·번역·재배포 조건은 이번 조사에서 확인하지 않았다. [IPA 공식 안내](https://www.internationalphoneticassociation.org/content/ipa-chart)

## 5. 다국어 공통 구조

공통화할 것은 소리의 특성을 표현하는 방식과 학습 흐름이다. 실제 목표 발음, 허용되는 변이, 설명, 예시는 언어별 검수 콘텐츠로 관리한다. 같은 철자나 IPA 기호를 이유로 모든 언어에 같은 지시를 적용하지 않는다.

| 계층 | 공통으로 저장할 것 | 언어·변이에 따라 달라질 것 |
|---|---|---|
| 목표 | 언어 태그, 변이, 소리/운율 목표, 단어 안 위치와 앞뒤 문맥 | 음소 대조, 실제 실현, 허용되는 변이, 예외 |
| 조음 | 관련 기관, 접촉 위치, 입술·턱 움직임, 공기 흐름, 성대 진동, 시간 순서 | 그 목표에 유용한 단서와 대안적인 발음 방법 |
| 운율 | 높낮이, 길이, 강세, 리듬, 경계 | 해당 언어에서 의미·자연스러움에 영향을 주는 패턴 |
| 설명 | 한 문장 안내, 자세한 설명, 그림·음성, 출처·검수 버전 | 설명 언어, 학습자의 배경에 맞는 비교 예시 |
| 지원 범위 | 자료 보기 / 안내 연습 / 사람 피드백 / 자동 평가 가능 여부 | 언어·변이·소리별 실제 검증 수준 |

목표 언어와 설명 언어는 별도다. 예를 들어 스페인어 발음을 한국어로 설명할 수 있어야 한다. 학습자의 모어는 선택적 참고 정보이며, 그 언어 사용자에게 특정 오류가 반드시 있다고 단정하는 규칙으로 사용하지 않는다.

영어 /ɹ/에도 여러 조음 유형이 존재한다. 하나의 혀 모양만 정답으로 고정하지 않고, 맞지 않는 안내를 다른 검수된 설명으로 바꿀 수 있어야 한다. [SpeechStar MRI 코퍼스의 여러 /r/ 유형](https://seeingspeech.ac.uk/speechstar/mri-speech-corpus/)

자료의 다국어 구조를 지원하는 것과 모든 언어를 자동 평가하는 것은 구분한다. 미지원 언어에서도 기록·안내·전후 비교·친구 피드백은 제공하고, 근거 없는 자동 점수를 표시하지 않는다.

## 6. 권장 화면과 학습 흐름

```mermaid
flowchart LR
    A[내 문장 녹음·자동 저장] --> B[친구 피드백 또는 검증된 분석]
    B --> C[연습할 구간 한 곳]
    C --> D[조음·운율 단서 하나]
    D --> E[듣고 다시 말하기]
    E --> F[이전·이번·예시 비교]
    F --> G[새 문장에서 힌트 없이 말하기]
    G --> H[기록 연결·다음 연습 추천]
```

첫 화면에는 “이번에는 이 한 가지만 연습해요”라는 짧은 안내, 해당 음성 구간, 필요한 경우의 입 모양이나 높낮이 도식, 다시 말하기 동작을 둔다. 자세한 해부학 용어와 IPA는 펼쳐서 본다. 입 전체를 항상 보여주기보다 이번 목표에 필요한 기관과 움직임을 강조한다. 그림에는 텍스트 설명을 함께 제공하고 재생 속도·일시정지·동작 줄이기를 지원한다.

예를 들어 영어 /f/ 연습의 안내 후보는 “윗니와 아랫입술을 가볍게 맞대고, 공기를 계속 내보내 보세요”이다. 이를 /p/와 구별하는 듣기·발화 연습으로 연결할 수 있다. 이는 수업 문구의 예시이지, 사용자의 녹음에서 실제 접촉 위치를 알아냈다는 진단이 아니다. 실제 배포 문구·그림·예시 음성은 언어별 검수 대상이다. 조음 분류의 기준은 [IPA 공식 차트](https://www.internationalphoneticassociation.org/content/ipa-chart)를 참고한다.

친구의 역할은 “어느 구간이 어떻게 들리는지”와 유용한 예시를 남기는 것이다. 앱은 그 구간에 적합한 검수된 안내를 연결한다. 친구가 쓴 개인적인 팁과 검수된 공식 설명은 출처를 구분한다. 모어 화자라는 이유만으로 해부학 설명의 정확성을 보증하지 않는다.

한 번의 연습에서 모든 오류를 나열하지 않는다. 사용자의 목표와 관련성이 높은 항목을 우선 추천하고 “다른 힌트 / 나중에 / 도움이 안 됨”으로 조정한다. 듣기 구별이 어려운 사람은 짧은 듣기 연습을 먼저, 이미 구별하는 사람은 바로 말하기로 이동하게 한다. 듣기와 말하기의 향상은 별도로 확인한다. [지각 훈련과 발화 전이에 관한 메타분석](https://doi.org/10.1017/S0142716417000418)

녹음 시작은 사용자의 명확한 행동에 연결하고, 녹음 상태를 계속 표시한다. 자동 종료를 제공하더라도 긴 침묵을 오류로 잘라내지 않도록 복구를 고려한다. 화면 이탈 후에도 복원할 초안과 서버에 도착한 음성을 구분한다. 이전 시도는 덮어쓰지 않고, 화면에서는 최근·대표 시도만 보여 기록이 과도하게 쌓여 보이지 않게 한다.

## 7. 기존 코드에 연결하는 방법과 선행 문제

**가장 먼저 자기 카드 연습을 가능하게 해야 한다.** 현재 `StudyCardService`는 카드 작성자와 학습자가 같으면 시도 제출을 거부한다. 웹·모바일도 작성자를 예시 음성 제공자처럼 취급하는 분기가 있다. 개인 기록에서 자기 발음을 반복하는 흐름과 충돌한다. 작성·공유 권한과 학습자 역할을 분리하되, 커뮤니티 보상에서 자기 첨삭을 제한하는 규칙까지 일괄 해제하지 않는다. [서비스의 확인 위치](//wsl.localhost/Ubuntu/home/yeonjae/Desktop/Project/ToneBridge/backend/src/main/java/me/yeonjae/tonebridge/application/service/StudyCardService.java:146)

`CorrectionRequest`에는 이미 `targetLanguage`, `targetVariant`, `feedbackGoals`가 있고, `TimestampComment`에는 `start`, `end`, `comment`, `category`가 있다. 이를 활용하면 첨삭을 소리 구간·학습 목표와 연결할 수 있다. 현재 필드만으로 검수된 조음 수업이나 개인별 숙련 상태가 표현되는 것은 아니다.

권장 개념 모델은 아래와 같다. 지금 당장 모두 독립 테이블로 만들라는 의미는 아니다.

| 개념 | 필요한 책임 |
|---|---|
| 원본 기록 | 원래 문장·음성, 소유자, 공개 범위, 저장 상태, 수정 버전 |
| 발음 목표 | 언어·변이·음소 또는 운율 목표·문맥·허용 실현 |
| 검수된 안내 | 한 문장 단서, 대안 설명, 그림·예시 음성, 연습 단계, 출처·권리·검수자·버전 |
| 피드백 관찰 | 원본 음성 및 구간, 사람/자동/자기평가 출처, 관찰 내용과 연습 제안의 구분, 연결한 안내 버전 |
| 학습 시도와 상태 | 학습자·원본·목표 연결, 시도별 녹음, 듣기/안내 발화/힌트 없는 적용 결과, 다음 연습 시점 |

음성 구간은 해당 녹음 버전에 연결하고 실제 길이 안인지 확인한다. 첨삭을 카드로 저장할 때 원본 요청·음성·구간·설명이 끊어지지 않아야 한다. 동일 첨삭 재저장과 업로드 재시도는 중복 항목을 만들지 않도록 처리한다. 자동으로 공유 세션을 선택하지 않고 개인 기록함을 기본으로 삼는다.

기존 1~5점과 1~10점 등의 점수 의미를 먼저 정리하고, 자동 분석 점수를 같은 척도로 보이게 섞지 않는다. AI 처리 실패를 실제 검토 완료처럼 보이게 하는 fallback도 수정 대상이다. 현재 AI 경로는 텍스트를 전달하므로 음향 기반 교정이 이미 구현된 것으로 보아서는 안 된다. 상세 확인 위치는 [앞선 검토의 E6·E8·E11](tonebridge-product-review.md)에 정리했다.

## 8. 콘텐츠 운영과 자동화 경계

콘텐츠는 출처 조사 → 권리 확인 → 언어별 작성 → 음성학 검수 → 그림·음성 일치 확인 → 버전 발행 순으로 관리한다. 자동 번역 뒤에도 조음 지시의 의미가 유지되는지 확인한다. 실제 서비스에서 무작위 웹 자료를 즉시 요약해 혀 위치를 지시하거나 생성 이미지로 해부학적 정답을 만들지 않는다.

AI를 사용할 경우 승인된 콘텐츠에서 적합한 단서를 선택하고 문장 난이도를 조절하는 역할부터 검증한다. 확실하지 않으면 자동 평가를 보류하고 예시 비교·사람 피드백으로 이어간다. “혀가 뒤로 가 있습니다”처럼 관찰하지 않은 신체 상태를 단정하는 대신, 관찰 가능한 소리의 차이와 시도할 방법을 구분해 설명한다.

새 언어 추가 시 UI 번역만 완료하고 지원 완료로 표시하지 않는다. 지원 변이, 검수된 목표 목록, 예시 음성, 자동 평가 가능 항목, 미지원 시 동작을 함께 관리한다. 사용자에게는 단순한 기능 가능 여부로 보여주고 내부 구현 상세를 부담시키지 않는다.

## 9. 개선 우선순위와 완료 기준

| 순서 | 작업 범위 | 완료를 판단할 기준 |
|---|---|---|
| 1. 학습 기반 복구 | 자기 카드 연습, 초안 복구·저장 상태, 첨삭 원본 연결, 점수·AI 상태 정리 | 자신의 기록을 다시 연습할 수 있고, 실패·재시도 뒤에도 원본과 새 시도가 중복·유실되지 않음 |
| 2. 공통 구조의 작은 검증 | 서로 다른 특성의 최소 두 언어 콘텐츠 묶음. 구체 언어는 실제 학습자와 검수 가능 인력 기준으로 선정 | 동일 화면·데이터 구조가 두 언어를 수용하고 설명 언어를 따로 바꿀 수 있음. 미지원 항목을 정직하게 표시 |
| 3. 한 구간 학습 완성 | 친구 피드백 → 한 가지 안내 → 다시 녹음 → 전후 비교 → 새 문장 적용 | 사용자가 제목·폴더·자료 검색 없이 흐름을 마치고 다음에 기록을 찾을 수 있음 |
| 4. 개인화·복습 | 반복 어려움 묶기, 학습자별 목표 상태, 필요한 항목만 다시 제시 | 자동 추천을 쉽게 수정·제외할 수 있고 같은 오류가 여러 카드로 복습 큐를 채우지 않음 |
| 5. 자동 평가 확대 | 언어·변이·목표별 검증, 낮은 신뢰도 보류, 실제 알림 전달 검증 | 사람 평가와의 불일치·잘못된 교정·미지원 처리에 관한 사전 기준을 충족한 범위만 활성화 |

첫 버전부터 전 언어 실시간 음소 채점, 3D 구강 모델, 임의 자료 자동 수집, 복잡한 알림 체계를 동시에 구축하는 것은 우선순위가 낮다. 공통 구조는 처음부터 마련하고, 콘텐츠와 자동 평가 범위는 증거에 따라 넓힌다.

## 10. 효과를 검증할 방법

조음 안내가 있는 방식과 음성 예시·반복 연습만 있는 방식을 **같은 학습 시간**으로 비교한다. 두 조건의 피드백 양과 연습 기회가 크게 달라지면 그림의 효과라고 해석하기 어렵다. 소규모 사용성 검증은 화면 이해와 연습 지속을 확인하는 용도이며, 통계적인 학습 효과를 입증했다고 주장하지 않는다.

학습 전, 직후, 약 일주일 뒤를 확인하되 같은 문장 따라 읽기 외에 연습하지 않은 단어·새 문장·힌트 없는 발화를 포함한다. 듣기는 다른 화자의 예시도 사용한다. 평가자는 어느 조건의 전후 녹음인지 모르는 상태에서 무작위 순서로 듣게 하고, 알아들은 내용과 이해하기 쉬운 정도를 구분한다. 목표 변이의 허용 범위를 오류로 벌점 처리하지 않는다.

주요 지표는 저장 복구 성공률, 첨삭에서 재연습까지 걸리는 시간, 힌트 없이 새 문장에서 목표를 사용할 수 있는지, 지연 후 유지, 잘못된 안내 비율이다. 녹음 수·클릭 수·주관적인 도움 평가만으로 발음 개선을 판정하지 않는다. 음질 문제와 낮은 확신 때문에 평가를 보류한 사례도 함께 집계한다.

이 검토에서 권하는 다음 산출물은 **자기 기록 한 건이 친구의 구간 피드백을 거쳐 다국어 공통 연습 화면과 다음 복습으로 이어지는 수직 흐름의 명세**다. 기존 구현의 연결 문제와 콘텐츠 검수 기준을 함께 다뤄야 새 발음 자료가 실질적인 학습으로 이어진다.
