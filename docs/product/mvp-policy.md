# ToneBridge MVP 제품 정책

## 서비스 정의

ToneBridge는 친구와 표현·예시 음성·연습 녹음·피드백을 주고받으며 함께 언어를 배우는 공간이다.
누군가를 먼저 교정해야 이용할 수 있는 교환 경제를 전제로 하지 않는다.

- 친구와 학습하는 기본 기능은 무료이며, 잔액·충전·기여 횟수를 이용 조건으로 삼지 않는다.
- 친구가 없어도 개인 연습장에 글과 음성을 저장하고 연습할 수 있다.
- 커뮤니티도 핵심 기능으로 유지한다. MVP에서는 공개 요청과 피드백에 크레딧을 쓰거나 지급하지 않는다.
- 공개 요청을 올릴 때 공유 대상을 사용자가 선택한다. 개인·친구 기록을 자동으로 공개하지 않는다.
- 복습은 선택이다. 세션 수를 미완료 과제처럼 세거나 매일 할 일을 만들어 내지 않는다.
- 목표는 가입 수보다 친구 두 사람이 실제로 예시 → 시도 → 피드백 → 재시도를 이어가는지 검증하는 것이다.

## 기록과 역할

StudySession은 계속 사용하는 연습장이다. 통화 한 번이나 녹음 한 번과 동일시하지 않는다.
연습장 종료 API는 기존 호환 동작을 유지하며, 통화 종료가 연습장 폐쇄를 뜻해서는 안 된다.

카드 작성자, 예시 제공자, 연습자, 피드백 작성자를 서로 다른 역할로 다룬다.
두 참여자 모두 같은 카드에 예시와 자신의 연습을 남길 수 있다. 카드 소유권과 수정·삭제 권한은 별개다.
피드백은 설명과 실제 녹음이 중심이며 점수는 선택이다.

학습 언어, 목표 발음 변형, 예시 제공자의 언어 배경, 설명 언어는 서로 구분한다.
국가를 발음 규범으로 간주하거나 원어민만 정답을 제공한다고 표현하지 않는다.

## 크레딧 전환 계약

| 항목 | MVP 정책 |
| --- | --- |
| 가입 | 신규 사용자 잔액 0, 가입 보너스·거래 기록 생성 없음 |
| 텍스트·음성 공개 요청 | 비용 0, 잔액 검사·차감 없음 |
| 피드백·채택·연속 참여 | 크레딧 보상 없음. 품질 검사·알림·참여 기록은 유지 |
| 관리자 조정 | UI 제거, 기존 조정 API는 410 / CREDIT_002 |
| 기존 잔액·거래 | 보존. 일괄 초기화·삭제·자동 환급 없음 |
| API 숫자 필드 | 구버전 클라이언트 호환을 위해 유지. 새 요청·교정은 0 |
| 이전 이벤트 | 양수 보상이 담긴 지연 이벤트도 지급하지 않음 |
| 지갑 링크 | 학습 홈으로 이동. 인증된 본인의 이력 API는 유지 |

크레딧 설정값을 0으로만 바꾼 것이 아니다. 서비스의 차감·지급 호출 자체를 제거하므로
이전 환경 설정이 남아 있어도 크레딧 정책이 다시 켜지지 않는다.

## 비용과 수익화

무료 기본 학습과 유료 외부 자원의 비용 통제는 분리한다. 업로드 크기·형식·요청 빈도 제한은 유지한다.
긴 음성의 전사·분석, AI, 통화 녹음 보관량은 실제 비용을 측정한 뒤 별도 사용 한도와 안내를 정한다.
무료라는 이유로 AI·통화·저장소를 무제한 제공한다는 약속은 하지 않는다.
크레딧·구독·결제 도입은 MVP 재방문과 비용 데이터가 쌓인 뒤 검토한다.

## 세 입력 방식의 역할

1. 짧은 비동기 음성: 지금 검증하는 핵심 학습 반복 과정.
2. 기존 메신저에서 얻은 음성 파일 가져오기: 향후 입력 확장. 외부 메신저 사용을 대체하도록 강제하지 않는다.
3. 앱 안의 사람 간 1:1 통화: 별도 통화 발생 기록과 동의 절차를 붙여 확장한다.

세 입력은 같은 연습장과 카드 기록으로 이어져야 한다. 개인 보관함과 공유 기록의 조회 범위를 구분한다.
긴 파일 분석·앱 내 통화·자동 전사는 현재 구현 완료 기능으로 안내하지 않는다.
