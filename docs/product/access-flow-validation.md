# 접속·PWA·첫 사용 개선 검증

기준: 2026-11-13, main 6b41e73에서 분리 작업트리로 시작.

## 확인 범위

- 로그인/초대 직접 진입의 공통 PWA 등록, 화면 이동 후 설치 이벤트 유지, 설치 안내 Dialog.
- 인증·학습 응답 캐시 제외, 이전 ToneBridge 캐시 정리, 오프라인 미방문 경로 안내.
- 가입 필드 오류와 포커스, 서버 실패 후 입력 유지, 정직한 계정 접근 안내.
- 보낸 요청의 인증·발신자 격리·요약 DTO·20개 페이지·수락 후 목록 제외.
- 개인 첫 단계 저장, 커뮤니티 최종 제출 유지, 기존 초안·멱등 저장 회귀.
- 공개 합성 음성 재생·피드백 예시, 기존 개인/친구/커뮤니티 흐름 회귀.

## 운영 전제와 남은 검증

메일 발송 모듈과 운영 환경 변수에 발송 서비스 설정이 없다. 자동 비밀번호 재설정은 미구현이며
계정 접근 도움말은 이 제한을 명시한다. 실제 발송 수단이 정해지면 단일 사용·단기 만료 토큰,
계정 존재 비노출 응답, 발송/검증 제한, 세션 폐기와 이메일 배달 검증을 별도 구현한다.

실제 iPhone/Android의 설치 창·아이콘·마이크·잠금 복귀·네트워크 전환은 미검증이다.
브라우저 설치 이벤트 모의 테스트와 실제 Chromium 서비스 워커/오프라인 검증을 구분한다.
테스트 API와 마이크는 fixture이며 운영 사용자에게 요청·피드백·문의 메시지를 보내지 않는다.
예시 WAV는 Windows Microsoft Zira Desktop으로 생성한 설명용 합성 음성이다.
PNG는 기존 T 마크를 경로로 재현한 `scripts/generate-pwa-assets.cjs`에서 생성한다.

## 변경 위험과 배포

DB 마이그레이션은 없다. 기존 친구 API와 Flutter 계약은 유지한다. 새 sent 조회 API 때문에
기존 CI의 backend → frontend 배포 순서를 유지한다. 인증 필터와 기존 저장 권한 검사는 변경하지 않는다.
PWA v3가 이전 ToneBridge 캐시를 제거하지만 계정별 IndexedDB 초안은 삭제하지 않는다.
