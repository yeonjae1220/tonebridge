# 친구 중심 사용자 흐름

제품 기준: [MVP 정책](mvp-policy.md). 현재 구현과 후속 설계를 아래에서 구분한다.

## 처음 시작하기

랜딩 → 가입/로그인 → 언어 프로필 설정 → 친구와 연습 홈.

랜딩은 친구와 함께 배우는 가치를 설명하고 무료 시작을 안내한다. 지급 크레딧이나 지갑은 노출하지 않는다.
친구 학습을 먼저 제시하고, 개인 연습·커뮤니티도 같은 홈에서 접근할 수 있다.
친구가 없는 사용자는 친구 추가 또는 개인 연습을 선택할 수 있다.

웹 온보딩은 모국어 → 학습 언어의 두 단계다. 이전 단계로 돌아가도 선택을 유지하며,
닉네임 변경과 능숙한 언어는 선택 설정에서 입력한다. 모국어를 선택해도 UI 언어를 강제로 바꾸지 않는다.
랜딩의 학습 예시는 가입 없이 볼 수 있는 설명용 예시다. 실제 사용자의 공개 피드로 오인시키지 않는다.

웹 홈의 글 작성·녹음은 해당 입력 방식으로 작성 화면을 바로 연다. 마이크는 사용자가 녹음 시작을
눌러야 작동한다. 친구 연습장 생성은 화면 안의 모달로 표시하고, 전체 연습장 관리는 접을 수 있다.
친구 요청과 학습 피드백은 구분한다. 웹 홈의 ‘내 연습에 달린 피드백’은 최신 3개를 요약하고,
‘전체 보기’는 현재 접근 가능한 모든 연습장의 과거 시도를 포함한다. `/api/practice-feedback`는
본인 연습만 현재 참여 권한·활성 카드/연습장 조건으로 조회하며 기본 20개, 최대 50개씩 반환한다.
목록의 피드백 본문은 최대 500자 요약이며 전체 내용은 연결된 연습 기록에서 확인한다.
여러 연습장과 카드의 개별 조회를 이어 붙이지 않는다. 화면을 보는 동안 30초마다 갱신하고,
조회 실패는 빈 목록으로 바꾸지 않고 재시도를 제공한다. 읽지 않은 알림 수를 의미하지 않는다.

새로 작성·수정한 피드백에는 마지막 작성자와 수정 시각을 저장한다. 수정 시각 내림차순이며,
메타데이터 없는 과거 피드백은 연습일을 정렬 기준으로 쓰고 작성자·피드백 시각 미기록을 표시한다.
과거 정보를 추정해 채우지 않으며, 수정 이력 전체를 저장하는 기능은 아니다. 본인의 자기 피드백은
‘내 메모’로 구분한다. 피드백 선택 시 카드의 정확한 시도에 포커스하고 이전 기록도 자동으로 펼친다.
최근에 열었던 카드라도 재진입 시 연습 기록을 다시 조회하여 새 피드백이 캐시에 가려지지 않게 한다.


## 초대에서 함께 연습하기까지

초대한 사람: 친구 화면 → 초대 링크 복사 → 본인이 원하는 메신저에 공유.

초대받은 사람: 링크 열기 → 로그인/가입 → 필요한 언어 설정 → 초대한 사람 검색 결과 확인 →
친구 요청을 직접 전송.

초대한 사람: 요청 수락 → 친구 목록에서 연습장 열기 → 기존 두 사람의 연습장이 있으면 이어가기,
없으면 새 연습장 생성.

- 초대 링크는 공개 닉네임을 담은 /friends?invite=... 형식이다. 링크만으로 친구 연결이나 기록 접근 권한을 주지 않는다.
- 기존 Google 자동 닉네임도 DB/API 한도인 50자까지 초대로 처리한다. 가입·닉네임 변경의 20자 규칙은 유지한다.
- 검색 결과와 닉네임을 확인한 뒤 요청한다. 닉네임 변경 후에는 새 링크를 공유해야 한다.
- 웹에서 로그인 및 온보딩을 거쳐도 초대 목적지를 보존한다. 외부 URL로의 인증 후 이동은 거부한다.
- 모바일 앱에서도 링크를 복사할 수 있다. 수신 링크는 웹에서 열린다. 네이티브 Universal/App Link 연결은 후속 작업이다.
- 친구 추가·수락·연습장 생성에는 기존 서버 인증과 참여자 검사를 그대로 적용한다.
- 링크를 다시 열거나 새로 고침해도 친구 요청을 자동으로 생성하지 않는다.

## 학습 반복 과정

공유 연습장 → 표현 카드 → 예시 음성 → 내 연습 녹음 → 참여자의 피드백 → 다시 녹음 → 기록 조회.

누구든 예시와 자신의 연습을 남길 수 있다. 반복 녹음은 새로운 시도로 보존된다.
피드백 점수는 비워둘 수 있다. 녹음 권한 대기·녹음·저장 중에는 충돌하는 동작을 잠근다.
실패 시 같은 화면의 녹음·메모를 유지해 재시도할 수 있다.
앱 종료 뒤 초안 복구와 피드백 수정 이력 전체 보존은 아직 별도 구현이 필요하다. 마지막 작성자와 수정 시각은 새 변경부터 저장한다.

웹 카드는 표현 → 예시 듣기 → 녹음 → 연습 기록/피드백 순으로 배치한다. 메모는 접을 수 있고,
저장된 각 연습 음성을 재생하여 이전 시도와 비교할 수 있다. 피드백에서 다시 녹음을 시작할 수 있다.
연습 기록은 최신 5개부터 보이며 ‘전체 / 내 연습 / 상대 연습’ 필터와 ‘더 보기’를 제공한다.
녹음과 받은 피드백을 우선 표시하고, 입력창과 선택 점수는 작성/수정을 눌렀을 때만 펼친다.
피드백 저장 실패 시 해당 입력창에 오류를 표시하고 내용을 유지한다. 직접 연결한 시도가 없으면
삭제·권한 변경 가능성을 알린다. 기존 시도 조회 API의 응답은 유지하며 더보기는 웹 표시 단위를 조절한다.
카드 생성·수정·이동 창은 하단 탐색 메뉴보다 앞에 표시되며, 수정 실패 시 입력 내용을 유지한다.
녹음 창은 마이크 권한을 기다리는 중에도 닫을 수 있다. 취소 뒤 권한이 늦게 허용되면 해당 스트림을
즉시 해제한다. 녹음 중에는 중지 버튼을 누른 뒤 창을 닫고 결과를 저장한다.

연습 음성은 `GET /api/attempts/{attemptId}/download-url`로 재생 URL을 받는다. 서버는 현재 카드와
연습장이 존재하고 요청자가 현재 참여자인지 확인한 뒤 저장된 음성 키로 15분 유효 URL을 발급한다.
탈퇴한 참여자·비참여자·삭제된 카드/연습장에는 새 URL을 발급하지 않는다. 이미 발급된 URL은 만료까지
유효할 수 있다. 기존 `/storage/presigned-download`는 커뮤니티 음성용이므로 연습 음성에 사용하지 않는다.
이 변경을 배포할 때는 새 API를 제공하는 백엔드를 웹보다 먼저 반영한다.

### 웹 녹음 유실 방지와 저장 재시도

- 미저장 음성은 인증 API로 확인한 계정·카드·녹음 목적별로 IndexedDB에 임시 보관한다.
  완료 안내 뒤에는 새로고침하거나 탭을 닫았다가 같은 계정·브라우저로 같은 화면을 열면 복구한다.
  예시 음성만 있으면 예시 탭을, 작성 화면에서는 음성 입력을 연다. 제출 전 작성 텍스트·공유 대상·언어/목표·작성 단계도 아래 별도 초안으로 복구한다.
- 복구된 녹음에는 확인 재생·카드 저장·파일 내려받기·확인 후 폐기 경로를 제공한다.
  임시 저장 중·실패·복구 완료를 구분한다. 저장소 차단·용량 초과·다른 탭의 변경 시에는
  복구 가능하다고 표시하지 않고, 현재 탭의 음성 유지와 다운로드·저장·재시도를 안내한다.
- 녹음 중에는 약 1초마다 누적 음성을 임시 보관한다. 종료 직전 이벤트에 의존하지 않는다.
  녹음 도중 닫으면 마지막으로 완료된 복구 지점까지만 복구하며, 마지막 구간 누락 가능성을 안내한다.
  브라우저가 이벤트를 지연하거나 프로세스를 종료하면 복구 간격이 길어질 수 있다.
- 링크·화면 이동 버튼과 새로고침에는 미저장 경고를 표시한다. 브라우저 뒤로가기는 가로채지 않고
  재진입 시 복원한다. 로그아웃·계정 변경에는 현재 계정의 임시 음성을 지우고 진행 중인 작업을 무효화한다.
  임시 녹음은 마지막 기록 후 7일까지 복구한다(만료 데이터는 다음 저장소 조회 시 정리).
  음성 한 건은 50 MiB, 저장소 전체는 100 MiB까지 보관하며, 초과 시 다른 녹음을 임의 삭제하지 않는다.
  브라우저 데이터 삭제·비공개 모드 종료·저장소 회수까지 복구를 보장하지 않는다.
  모바일에서는 beforeunload 경고 자체가 생략될 수 있다.
- 새 WebM 녹음은 오디오 샘플 길이를 측정해 컨테이너에 기록한다. 기존 길이 정보가 없는 음성은
  재생 위치를 바꾸지 않고 디코딩해 전체 길이 안내를 표시한다. 디코딩 미지원 시에도 재생은 유지한다.
  전체 길이는 기본 재생기·녹음 미리듣기와 같이 소수 초를 버린다(28.62초 → 00:28, 59.99초 → 00:59).
- 카드 연습·예시 저장은 준비 → 업로드 → 카드 저장 상태를 표시한다. 5초 이상 지연되면 안내하고,
  각 네트워크 단계는 30초 후 중단해 같은 녹음으로 재시도할 수 있게 한다. 백그라운드 타이머가
  OS에 의해 중단되는 동안에는 실제 경과 시간이 더 길어질 수 있다.
- 업로드가 끝났다면 재시도 시 같은 음성 키를 재사용한다. 서버는 활성 카드 행을 잠그고 현재
  참여자를 확인한 뒤, 연습은 카드·학습자·음성 키, 예시는 카드·음성 키가 같은 기존 결과를 돌려준다.
  응답 유실·동시 재전송으로 학습 기록이 중복되지 않는다. 새로 녹음한 음성은 새로운 시도다.
  임시 저장이 정상인 카드 녹음은 완료된 업로드 키도 보관해 새로고침 뒤 재시도에 재사용한다.
  토큰·서명 URL은 저장하지 않는다. 저장소 장애 시 메모리 재시도만 가능하다.
- 작성 화면도 개인·친구·커뮤니티의 텍스트/음성 저장을 계정별 요청 UUID로 식별한다.
  음성을 먼저 업로드하고 연습장·카드·음성 연결(또는 교정 요청)과 완료 영수증을 한 DB 트랜잭션으로 저장한다.
  중간 실패는 전체 롤백한다. 실패한 카드를 보상 삭제하거나 재시도마다 새 카드를 만들지 않는다.
- 제출 전 텍스트·맥락·입력 종류·공유 대상/친구·언어/지역·피드백 목표·단계·원본 카드 ID를
  계정별 편집 초안으로 자동 보관한다. 저장 버튼을 누르지 않아도 보관 완료 후 같은 브라우저에서
  reload/탭 종료 복구가 가능하다. 초안은 마지막 변경 후 7일이며 로그아웃/계정 변경 때 정리한다.
  토큰·서명 URL은 포함하지 않는다. 복구한 초안은 새 링크의 목적지나 늦은 원본 카드 조회로 덮어쓰지 않는다.
- 여러 탭은 Web Locks와 revision을 비교해 오래된 탭의 자동 덮어쓰기를 거부한다.
  필요한 내용을 내려받은 뒤 명시적으로 확인한 재시도만 현재 내용으로 초안을 교체한다.
  제출용 스냅샷이 우선하며 제출 직후 자신의 편집 초안만 tombstone으로 정리하고 다른 탭의 새 초안은 유지한다.
- 저장소 차단·용량 부족·초안 충돌·손상·기타 실패를 구분한다. 현재 입력과 음성은 유지하며
  새로고침/종료 대신 텍스트와 설정 파일·음성 다운로드, 같은 화면의 임시 보관 재시도를 제공한다.
  브라우저 경고가 생략되는 상황에서는 아직 보관 중이거나 실패한 변경의 복구를 보장하지 않는다.
- 제출 직전 작성 내용·공유 대상·요청 UUID·업로드 완료 여부를 이 브라우저에 7일간 보관한다.
  새로고침 뒤 ‘이어서 저장’은 서버의 이전 결과부터 조회하고 완료된 업로드를 건너뛴다.
  업로드 자체가 실패하거나 응답이 유실되어 다시 업로드해도 같은 예약 키를 사용한다.
  요청별 불변 녹음 사본을 기존 IndexedDB 한도 안에 보관한 뒤 제출해 다른 탭의 새 녹음과 섞이지 않는다.
  저장 성공 시 원본 녹음 revision이 달라졌으면 그 새 녹음을 유지한다.
  로그아웃/계정 변경으로 임시 정보가 무효화되며 토큰과 서명 URL은 보관하지 않는다.
- 제출 이후 입력을 고정하고 확인·업로드·저장 단계를 표시한다. ‘저장 상태 확인 후 수정’은
  이미 완료된 결과를 열거나, 미완료 요청을 서버에서 취소한 뒤 기존 내용의 편집을 허용한다.
  취소 표식은 다른 탭에서 늦게 도착한 저장도 거부한다. 오프라인이면 상태 확인 후 다시 시도한다.
- 서버는 계정 행 잠금으로 동시 재시도를 직렬화하고 같은 요청의 다른 내용을 409로 거부한다.
  완료된 UUID는 삭제된 리소스를 새로 만들지 않으며 현재 참여 권한도 다시 확인한다.
  프론트는 Web Locks로 여러 탭의 새 요청 번호 발급을 직렬화한다. 로컬 저장에 실패하면
  복구할 수 없는 새 요청을 시작하지 않는다. 서버의 중복 방지가 제공되도록 백엔드부터 배포한다.

검증 범위: 브라우저 자동화는 데스크톱과 모바일 레이아웃을 분리해 실행하고, Android 에뮬레이터의
실제 Chrome/MediaRecorder에서 녹음·복원·지연·재시도·저장 후 재생을 추가 확인한다. 에뮬레이터의
호스트 마이크는 끈다. 실제 Android/iPhone의 마이크 품질, Safari 코덱, 잠금·백그라운드 복귀,
통화·Bluetooth 전환과 실제 모바일 망 변화는 별도의 실기기 검증 항목이다.

## 개인 연습과 커뮤니티

개인: 홈 → 내 연습장 → 카드/녹음 저장. 친구가 없어도 가능하다.

커뮤니티: 커뮤니티 요청 버튼 → 내용 작성 → 공개 대상 확인 → 언어·피드백 목표 → 제출.
진입 버튼의 COMMUNITY 의도를 작성 화면에 전달하되 사용자가 대상을 바꿀 수 있다.
요청은 잔액 0에서도 가능하며, 다른 사람의 피드백에 답하거나 채택해도 크레딧 거래가 발생하지 않는다.

개인·친구·커뮤니티는 서로 다른 저장/공개 경로다.
기존 개인·친구 카드를 자동 게시하거나 원본 통화 전체를 공개하는 흐름은 만들지 않는다.

웹 카드의 커뮤니티 요청은 공개 대상을 유지하고, 권한이 확인된 카드의 표현·상황만 작성 초안에
복사한다. 원본 녹음·메모는 복사하지 않는다. 사용자가 내용을 검토하고 최종 제출해야 공개되며,
원본 카드를 읽지 못하면 작성 화면에서 오류와 재시도를 표시한다.

## 권한과 관계 해제

연습장 접근은 현재 session_members에 포함되는지 서버에서 확인한다.
소유자라는 이유로 참여자 검사 없이 접근할 수 없다. 친구 요청 수락은 지정된 수신자만 가능하다.

웹의 ‘연습장 나가기’는 본인의 session_members만 제거한다. 본인이 만든 카드·음성을 포함해
해당 연습장을 더 이상 조회/수정하거나 새 음성 URL을 받을 수 없으며, 남은 참여자의 접근은 유지한다.
나간 작성자도 연습장 이름 변경·삭제 권한으로 우회할 수 없다. 상대가 먼저 나가 혼자 남은 비작성자도
나가기를 사용할 수 있다. 이 작업은 원본 삭제가 아니다.

친구 삭제 확인창은 ‘두 사람의 기존 공유 연습장 접근도 종료’ 선택을 제공한다. 기본은 미선택이다.
- 미선택: 친구 관계만 제거하고 기존 공유 접근은 유지한다. 구버전/네이티브 클라이언트도 이 동작을 유지한다.
- 선택: 현재 두 사람이 함께 참여 중인 모든 연습장에서 두 사람의 membership을 제거하고 친구 관계를
  같은 트랜잭션으로 삭제한다. 다른 상대와의 연습장 및 개인 연습장은 건드리지 않는다.
- 친구 관계 잠금은 공유 연습장 생성과 동일한 잠금을 사용하므로 동시 생성이 종료를 우회하지 않는다.
- 원본 연습장·카드·시도·예시 음성은 보존한다. 개인 연습장으로 자동 복사하지 않으며, 다시 친구가 되어도
  종료된 연습장의 접근을 자동 복원하지 않는다. 이미 한 사람이 나간 연습장은 ‘현재 공동 참여’ 범위가 아니다.

확인창에서 양쪽 영향과 보존 범위를 설명한다. 기존 발급 음성 URL은 최대 15분 유효할 수 있고,
다운로드된 사본은 회수할 수 없다. 열린 화면에 이미 내려받은 내용을 원격으로 지우는 기능도 아니다.
웹은 성공 시 연습장·카드·음성 URL·피드백 캐시를 비운다. 실패 시 선택을 보존하여 명시적으로 재시도한다.
영구 삭제와 접근 복구가 필요하면 `/help`로 문의하며 운영자가 본인·대상 범위를 확인한다.
신규 친구 요청까지 막는 ‘사용자 차단’과 개인 기록 내보내기는 별도 후속 기능이다.


## 브라우저 초안 관리

연습장 화면의 `초안 관리`에서 현재 계정·브라우저에 보관 완료한 작성 내용/설정과 카드별 연습·예시 녹음을 확인한다.
목록은 마지막 보관 시각과 대상/원래 카드 문장을 보여주고 이어쓰기·다운로드·선택 폐기를 제공한다.
편집 초안은 기존 계정별 한 벌이며 새 다중 문서 편집기나 기기 간 동기화를 추가한 것은 아니다.
저장 결과 확인이 필요한 제출 건은 별도 항목으로 표시하고 기존 작성 화면에서 확인·재시도·편집한다.
목록에서 제출 영수증을 직접 폐기하거나 서버 저장 내용을 삭제하지 않는다. 카드 접근이 사라져도 로컬 녹음을 내려받을 수 있다.
다른 탭에서 바뀐 초안은 오래된 목록으로 삭제하지 않으며 목록 재확인과 재시도를 안내한다.
텍스트 내보내기는 친구 표시 이름·언어/변형 이름·번역된 목표·내려받은 시각과 시각 포함 파일명을 사용한다.
친구 정보를 조회할 수 없으면 UUID 대신 확인 불가로 표시한다. 정상 보관 안내의 상세/다운로드는 접고 복구·오류·중단은 펼친다.
기존 7일 TTL·로그아웃 무효화·저장소 회수 한계는 유지한다. 실기기·iPhone 검증은 별도다.

## 입력 확장 설계 — 아직 구현하지 않음

- 파일 가져오기: 파일 선택 → 참여자 권한/동의 확인 → 비공개 보관 → 필요한 구간 선택 → 카드 생성.
  긴 파일은 비동기 처리 상태와 실패 재시도를 보여준다. 분석 실패가 원본 저장을 막지 않도록 분리한다.
- 1:1 통화: 친구 선택 → 통화 참여 → 녹음 동의 → 통화 → 통화 후 필요한 표현을 카드로 정리.
  통화와 분석 작업은 분리하고, 통화 종료 후에도 기존 연습장은 계속 사용한다.
- 공통: source 종류·원본 구간·참여자·작성자·재시도 관계를 보존한다. 세션에 통화 생명주기를 억지로 넣지 않는다.
- RTC 공급자와 요금제는 아직 선택하지 않았다. iOS/Android의 백그라운드·권한·재연결 검증 후 결정한다.

## 피드백·공유 종료 변경의 배포 계약

Flyway V26.1(`V26_1__practice_feedback_metadata.sql`)은 별도 파일럿 작업의 V27보다 앞선다.
기존 V27 파일이나 작업트리를 수정하지 않는다. V26까지 적용된 main에서는 26.1 → 27 순서로 진행한다.
이미 별도 환경에 V27을 먼저 적용했다면 Flyway 이력을 확인하고 명시적인 통합 절차를 정한 뒤 배포한다.
새 피드백 조회 API와 공유 종료 옵션을 처리하는 백엔드를 먼저 배포한 뒤 웹을 배포한다. 구 백엔드는
알 수 없는 closeShared 옵션을 무시할 수 있으므로 새 웹을 구 백엔드에 연결해서는 안 된다.
롤백은 추가 컬럼을 삭제하지 않고 이전 앱 버전으로 돌아간다. 이미 제거한 membership을 자동 복원하지 않는다.
