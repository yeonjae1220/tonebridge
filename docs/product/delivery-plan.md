# 크레딧 없는 MVP 전환 및 검증

기준: 2026-10-29 · [정책](mvp-policy.md) · [흐름](user-flows.md)

## 이번 변경의 범위

- README와 제품 문서를 친구 중심 무료 학습 기준으로 정리.
- 가입·요청·교정·채택·연속 참여의 크레딧 효과 제거, 지연 이벤트 보상 차단.
- 기존 잔액/이력과 호환 DTO 유지, 관리자 조정 종료.
- PostgreSQL V25: 요청 비용 0 허용, 신규 계정 잔액 기본값 0. 과거 행은 갱신하지 않음.
- 웹/모바일의 크레딧 비용·보상·지갑 진입 제거, 랜딩/가입/커뮤니티 안내 9개 UI 언어 수정.
- 친구 중심 홈, 근거 없는 오늘 할 일 숫자 제거, 웹·모바일 친구 목록에서 공유 연습장 이어가기.
- 웹 초대 목적지의 로그인/가입/온보딩 복원, 웹·모바일 초대 링크 복사.
- 커뮤니티 작성 진입 의도 유지. 기존 예시·연습·피드백·재시도 기능은 재사용.
- PR에서도 Flutter 테스트가 실행되도록 CI 검증 위치 이동.

코드와 로컬 검증 완료는 운영 반영과 다르다. 커밋·PR·배포·실기기 검증은 별도 상태로 보고한다.

## 검증 기준

| 계층 | 확인할 동작 |
| --- | --- |
| PostgreSQL + API | 잔액 0의 텍스트/음성 요청 성공, 비용 0 저장, 거래 0건 |
| 기존 데이터 | 잔액·이력 유지, 채택/지연 이벤트/7일 참여에도 신규 지급 없음 |
| 인증/권한 | 관리자 조정 410, 일반 사용자의 관리자 API 접근 거절, 본인 이력만 조회 |
| 친구 연습 | 두 참여자의 예시/연습/피드백/재시도, 비참여자 접근 거절 |
| 웹 브라우저 | 초대 쿼리 로그인 보존, 온보딩 후 복귀, 요청 자동 전송 없음, 친구 홈 및 지갑 링크 |
| 모바일 | 학습·요청·녹음·피드백 회귀, 0잔액 사용자, 작은 화면/확대 글자 |
| 문구 | 9개 언어 랜딩/가입/커뮤니티에 시작 크레딧·보상 약속 없음 |

실기기 마이크·iOS Safari·Android 오디오·메신저 인앱 브라우저는 모의 마이크/위젯 테스트와 구분한다.

## 로컬 검증 결과 — 2026-10-29

- Backend: 119개 테스트 성공, 실패/건너뜀 0. PostgreSQL Testcontainers와 V25 실제 마이그레이션 포함.
- Flutter: 89개 테스트 성공. 친구 연습장 재사용/신규 생성/조회 실패 재시도 테스트와 조회/생성 대기 중 친구 삭제 회귀 테스트 2개 포함.
- Playwright: 30개 성공. 데스크톱 및 모바일 화면 크기에서 로그인·가입·온보딩 초대 복귀,
  외부 리다이렉트 차단, 무료 요청 의도, 예시·연습·피드백·실패 재시도 확인.
- 웹 production build, type-check, lint 성공. 9개 언어의 공개 진입 문구에 크레딧 약속이 없는지 확인.
- Flutter analyze: 컴파일 오류 없음. 기존 auth_repository_impl.dart:113의
  unawaited_return_in_try_block 경고 1개와 스타일 진단이 있어 전체 분석 명령은 non-zero로 종료.
- 배포 순서 회귀 테스트 3개 성공: 백엔드 완료 전 웹 변경 금지, 백엔드 적용/롤아웃 실패 시 웹 변경 없음,
  웹 롤아웃 실패 전파. 실제 workflow 셸을 모의 kubectl로 실행하며 운영 클러스터에는 연결하지 않음.
- 기존 Google 닉네임 23/50자의 로그인 후 초대 복귀·명시적 요청과 모바일 버튼 접근성 검증.
  51자/잘못된 문자 초대는 검색·요청을 실행하지 않음. 실제 PostgreSQL API에서도 50자 검색과 PENDING 요청 확인.
- 변경한 Flutter 친구 화면 및 테스트 파일의 정적 분석 통과. 전체 Flutter 분석의 기존 경고는 아래 한계와 별개로 유지.
- 배포 순서·브라우저·Flutter 회귀 테스트를 PR/push CI에 연결. CI YAML 구조 확인, git diff --check 통과.
- 브라우저 마이크와 API는 모의 입력. 실제 휴대폰 녹음·통화·운영 반영은 미검증.

보안 검토는 새 초대가 권한을 부여하지 않는지, 인증 후 이동이 외부 URL을 거부하는지,
연습장 참여자 검사 및 관리자 경계가 유지되는지에 집중했다. 전체 의존성 취약점 검사는 실행하지 않았다.

## 배포 순서와 되돌리기

1. 변경 diff와 로컬 테스트를 검토한다. 현재 작업은 운영 DB를 변경하지 않는다.
2. CI는 V25와 서버를 먼저 적용하고 백엔드 rollout 성공 뒤에만 웹 매니페스트와 이미지를 갱신한다.
   백엔드 적용/롤아웃 실패 시 웹 변경 전에 종료한다. 운영 시 구버전 서버 트래픽 잔존 여부도 확인한다.
3. 웹과 모바일을 갱신한다. 설치된 이전 앱은 숫자 필드가 유지되어 파싱 가능하지만 오래된 보상 문구를 표시할 수 있다.
4. 운영에서 잔액 0의 학습·요청과 거래 미생성, 초대 복귀를 확인한다.
5. 장애 시 UI 수정만 되돌릴 수는 있지만, 크레딧 차감 코드가 있는 구버전 서버로 단순 롤백하지 않는다.
   V25를 되돌리면 이미 저장된 비용 0 행과 충돌한다. 스키마와 무료 정책을 유지한 수정 배포를 우선한다.

짧은 비동기 교환 검증과 함께 1:1 음성 통화의 실기기 기술 검증을 진행한다.
이후 파일 가져오기, 구간 선택, 통화 발생 기록과 녹음 동의, 통화 후 분석을 독립된 작업으로 구현한다.
긴 파일 전사·분석과 RTC는 실제 비용·보관 정책·iOS/Android 검증 없이 출시 완료로 표시하지 않는다.
외부 메신저 사용은 계속 허용하고, 사람 간 학습 통화를 다른 AI 전화 서비스와 혼합하지 않는다.

## MVP 측정 설계 — 계측 수집은 후속 구현

- 초대 링크에서 친구 관계 수락까지 도달한 비율.
- 수락한 두 사람이 7일 안에 첫 피드백을 주고받은 비율.
- 피드백을 받은 카드에 새 연습 시도를 남긴 비율.
- 다음 주에도 같은 친구 쌍이 함께 연습한 비율.
- 음성 저장량·처리 시간·실제 비용, 권한/업로드 실패율.

초대 클릭부터의 퍼널은 별도 이벤트 계측이 필요하다. 현재 데이터만으로 측정 완료라고 주장하지 않는다.
학습 내용·원본 녹음·토큰을 분석 이벤트에 넣지 않으며, 이벤트 최소화와 보관 기간을 먼저 정한다.
