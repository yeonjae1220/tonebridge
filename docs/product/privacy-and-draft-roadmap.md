## 승인된 기본 정책

- 웹/PWA UI 우선, 서버 차단은 기존 네이티브에도 적용. Flutter 호환성 검사; 네이티브 신규 화면·실기기 검증은 별도.
- 차단은 관계·대기 요청 정리와 두 사람의 기존 공유 접근 종료, 기록 보존. 해제로 관계/공유 자동 복구 안 함. 서버 상세/쓰기/음성/알림까지 판정.
- 내보내기는 본인 프로필·작성·학습·현재 열람 가능한 받은 피드백 및 선택한 본인 음성의 ZIP(JSON/설명/실제 파일). 비밀정보·타인 PII·내부 저장소 키/서명 링크 제외. 로그인 본인만 다운로드. 작업 상태/요청 제한/용량 제한/실패·만료 처리, 완료 파일 24시간 보관.
- 초안 동기화는 기본 꺼짐, 기존 초안 업로드는 선택. 로컬 복구 유지. 마지막 수정 후 7일, 초안별 최근 20개 이력(각 7일), 같은 내용 중복 저장 안 함. 복원은 새 버전. 충돌 때 내 수정/원격 수정/별도 초안 선택.
- 동기화 중단은 업로드 중단, 서버 자료 삭제 별도. 로그아웃은 로컬 정리·서버 유지, 탈퇴는 서버 초안/이력/파일 삭제. 삭제·제출 완료가 오래된 기기에서 되살아나지 않도록 버전·삭제 기록·재대조 처리. 접수 불명 제출은 기존 영수증 확인, 자동 게시/재제출 안 함.
- 녹음은 완료 파일만 동기화, 서버 업로드 예약/소유권/크기·형식 검증 후 확정. 실패 시 로컬 유지. 확정: 파일 50MiB, 계정 50초안(텍스트 포함)/100MiB(이력 참조 파일 포함). 텍스트 동의와 별도로 녹음 동의를 받는다. 미완료/만료/미참조 파일 정리와 실패 재시도.
- additive 마이그레이션, DB 변경 전 백업 확인, 서버 우선 배포. 기존 실사용자 데이터 쓰기·문의·메일 발송을 운영 검사에 사용하지 않는다. 차단 검사 없는 구버전으로 롤백하지 않는다.

## 녹음 구현·운영 기준

- 인증된 예약·파일 PUT·GET만 사용하고, 외부에 비공개 저장소 키나 업로드 서명 URL을 주지 않는다. 서버 생성 UUID, 소유자·동의 epoch·예약 크기·MIME·컨테이너 헤더·SHA-256을 대조한다. READY 파일은 재업로드로 바뀌지 않는다.
- 파일 업로드는 계정당 1개·서버당 2개, 예약은 시간당 30회. 미완료 예약 15분, 업로드 lease 5분과 정리 유예 2분. 현재 초안/미만료 이력이 참조하는 파일은 유지하고, 삭제 실패는 키를 남겨 재시도한다. 탈퇴 후에도 파일 정리용 메타데이터는 소유자 NULL로 남는다.
- 응답 유실은 같은 예약 상태와 초안 작업 영수증으로 대조한다. 확인된 실패 예약만 새 UUID로 재시도한다. 이력은 같은 파일을 중복 계산하지 않는다.
- 작성·피드백·연습·예시 제출은 기존 요청 ID를 유지한다. 연습/예시 API의 Idempotency-Key는 선택 항목이므로 기존 Flutter 요청은 호환된다. 서버 완료와 연결 초안 폐기를 한 트랜잭션으로 처리한다.
- 복원은 다운로드 전 로컬 수정 식별자를 잡고, 무결성 및 최신 서버 상태를 다시 확인한 뒤 IndexedDB에서 비교한다. 활성 녹음/새 수정/삭제 기록/계정 전환이 있으면 덮어쓰지 않는다. 제출용 녹음 저장은 잠금 안에서 완료한 뒤 화면으로 이동한다.
- 다시 녹음은 이전 서버 이력을 유지한다. 명시적 초안 폐기는 서버 확인 후 로컬을 지우며, 실패하면 다운로드·재생 가능한 로컬 녹음과 오류 안내를 유지한다.
