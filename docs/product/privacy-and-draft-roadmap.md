# 승인된 개인정보·초안 기능 작업 범위

2026-11-17 사용자 승인: 차단 → 개인 기록 내보내기 → 텍스트 초안 동기화·이력 → 녹음 초안 동기화. 각 단계 리뷰·회귀 테스트·검증·배포·운영 확인 후 다음 단계로 진행한다.

## 진행 상태

- 사용자 차단: 구현 및 검증 중. 아직 배포 완료 아님.
- 개인 기록 내보내기: 대기.
- 텍스트 초안 동기화·이력: 대기.
- 녹음 초안 동기화: 대기.

## 승인된 기본 정책

- 웹/PWA UI 우선, 서버 차단은 기존 네이티브에도 적용. Flutter 호환성 검사; 네이티브 신규 화면·실기기 검증은 별도.
- 차단은 관계·대기 요청 정리와 두 사람의 기존 공유 접근 종료, 기록 보존. 해제로 관계/공유 자동 복구 안 함. 서버 상세/쓰기/음성/알림까지 판정.
- 내보내기는 본인 프로필·작성·학습·현재 열람 가능한 받은 피드백 및 선택한 본인 음성의 ZIP(JSON/설명/실제 파일). 비밀정보·타인 PII·내부 저장소 키/서명 링크 제외. 로그인 본인만 다운로드. 작업 상태/요청 제한/용량 제한/실패·만료 처리, 완료 파일 24시간 보관.
- 초안 동기화는 기본 꺼짐, 기존 초안 업로드는 선택. 로컬 복구 유지. 마지막 수정 후 7일, 초안별 최근 20개 이력(각 7일), 같은 내용 중복 저장 안 함. 복원은 새 버전. 충돌 때 내 수정/원격 수정/별도 초안 선택.
- 동기화 중단은 업로드 중단, 서버 자료 삭제 별도. 로그아웃은 로컬 정리·서버 유지, 탈퇴는 서버 초안/이력/파일 삭제. 삭제·제출 완료가 오래된 기기에서 되살아나지 않도록 버전·삭제 기록·재대조 처리. 접수 불명 제출은 기존 영수증 확인, 자동 게시/재제출 안 함.
- 녹음은 완료 파일만 동기화, 서버 업로드 예약/소유권/크기·형식 검증 후 확정. 실패 시 로컬 유지. 초기 제안: 파일 50MB, 계정 50초안/100MB(이력 참조 파일 포함); 실제 저장소·기존 제한 확인 후 확정. 미완료/만료/미참조 파일 정리와 실패 재시도.
- additive 마이그레이션, DB 변경 전 백업 확인, 서버 우선 배포. 기존 실사용자 데이터 쓰기·문의·메일 발송을 운영 검사에 사용하지 않는다. 차단 검사 없는 구버전으로 롤백하지 않는다.
