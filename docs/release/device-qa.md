# 실기기 QA 체크리스트 (4단계)

기준일: 2026-11-25. 스토어 제출 전에 **실기기**에서 확인한다. 시뮬레이터·에뮬레이터는 마이크·블루투스·통화 중단·
Play 서명 키를 재현하지 못한다.

## 준비

| 항목 | iOS | Android |
|---|---|---|
| 빌드 | TestFlight (`make store-ios` → App Store Connect 업로드) 또는 케이블 연결 후 Xcode 실행 | Play 내부 테스트 트랙 (`make store-android` → 업로드) |
| 왜 스토어 경유인가 | 배포 프로비저닝·Sign in with Apple 권한이 실제 제출본과 같아진다 | **Play 앱 서명 키**로 재서명된 빌드여야 Google 로그인 SHA-1 문제를 잡는다. 직접 설치한 APK는 업로드 키로 서명돼 있어 이 문제가 안 드러난다 |
| 선행 조건 | App ID에 Sign in with Apple 켜기 + 프로파일 재생성 | Android OAuth 클라이언트 2개(업로드 키·앱 서명 키 SHA-1) |
| 백엔드 | 운영(`tonebridge.mungji.com`)에 V36 + 모바일 로그인 API 배포 완료 | 동일 |

기록: 회차마다 기기 모델 · OS 버전 · 빌드 번호(versionCode / CFBundleVersion) · 날짜를 아래 결과표에 남긴다.

## 1. 설치·첫 실행

- [ ] 홈 화면 아이콘과 이름 `ToneBridge` (Android: 테마 아이콘 켜고 모노크롬 표시도 확인)
- [ ] 콜드 스타트 시 보라색 런치 화면 → 로그인 화면으로 자연스럽게 전환 (라이트·다크 모드 각각)
- [ ] 세로 고정 — 기기를 돌려도 화면이 회전하지 않음
- [ ] 기기 언어 ko / en / ja 에서 로그인 화면 문구가 그 언어로 나옴, 미지원 언어(예: 이탈리아어)는 한국어

## 2. 로그인

| # | 시나리오 | 기대 결과 |
|---|---|---|
| 2.1 | 이메일 가입 (새 이메일) | 온보딩으로 이동 |
| 2.2 | 로그아웃 → 같은 이메일 로그인 (대문자 섞어서) | 같은 계정으로 들어감 |
| 2.3 | 틀린 비밀번호 | 시트 안에 "이메일 또는 비밀번호가…" 문구, 시트 유지 |
| 2.4 | Google 로그인 (Play 내부 테스트 빌드) | 성공. 실패하면 앱 서명 키 SHA-1 OAuth 클라이언트 누락 |
| 2.5 | Apple 로그인 — 이메일 공유 / **이메일 가리기** 각각 | 둘 다 성공. 가리기는 privaterelay 주소로 계정 생성 |
| 2.6 | Apple 로그인 두 번째부터 | 같은 계정 (Apple은 두 번째부터 이메일을 안 준다 — sub로 찾아야 함) |
| 2.7 | 이메일로 가입한 주소와 같은 Google 계정으로 로그인 | 같은 계정으로 들어가고, **이후 그 이메일 비밀번호 로그인은 실패** (선점 방지) |
| 2.8 | 앱 종료 후 하루 뒤 재실행 | 로그인 유지 (refresh 토큰 회전) |
| 2.9 | 비행기 모드에서 로그인 시도 | "서버에 연결할 수 없습니다" 문구, 앱이 멈추지 않음 |
| 2.10 | 로그인 화면의 이용약관·개인정보처리방침 링크 | 인앱 브라우저로 열림 (페이지 공개 후) |

## 3. 녹음·재생 (가장 위험한 영역)

| # | 시나리오 | 기대 결과 |
|---|---|---|
| 3.1 | 첫 녹음 — 마이크 권한 팝업 | 문구가 기기 언어로 나옴 (iOS) |
| 3.2 | 권한 거부 후 녹음 시도 | 설정으로 안내, 앱이 멈추지 않음 |
| 3.3 | 설정에서 권한 다시 허용 후 복귀 | 재시작 없이 녹음 가능 |
| 3.4 | 녹음 → 업로드 → 재생 | 소리가 정상, 길이 표시 일치 |
| 3.5 | **교차 재생**: iOS 녹음을 Android·웹에서, Android 녹음을 iOS·웹에서 | 모두 재생됨 (코덱·컨테이너 호환) |
| 3.6 | 녹음 중 화면 잠금 | 녹음이 멈추거나 이어지되, 깨진 파일이 업로드되지 않음 |
| 3.7 | 녹음 중 전화 수신 / 알람 | 녹음 중단 처리, 이후 다시 녹음 가능 |
| 3.8 | 블루투스 이어폰 연결 상태로 녹음·재생 | 입력·출력 장치가 예상대로 (재생이 통화 음질로 떨어지지 않는지) |
| 3.9 | 무음 모드 스위치 켠 상태로 재생 (iOS) | 소리가 나옴 |
| 3.10 | 업로드 중 네트워크 끊김 | 실패 안내, 재시도 가능, 중복 업로드 없음 |
| 3.11 | 최대 길이까지 녹음 | 제한에서 멈추고 정상 저장 |

## 4. 친구·학습 흐름

- [ ] 친구 요청 → 수락 (두 기기, 서로 다른 플랫폼)
- [ ] 공유 연습장에서 카드·예시 음성 주고받기 → 상대 기기에 반영
- [ ] 피드백 작성 → 상대가 확인 → 다시 연습
- [ ] 앱을 백그라운드로 보냈다가 복귀 — 실시간 갱신(SSE) 재연결
- [ ] 차단 / 신고 (해당 기능 머지 후)

## 5. 계정 삭제 (스토어 필수)

- [ ] 프로필 설정 → 계정 삭제 2단계 확인 → 로그인 화면으로
- [ ] 같은 Apple/Google/이메일로 다시 가입하면 **새 계정** (이전 데이터 없음)
- [ ] (Apple 토큰 revoke 구현 후) 설정 → Apple ID → Apple로 로그인 목록에서 ToneBridge가 사라짐

## 6. 스토어 빌드 고유 항목

- [ ] 릴리스 빌드에서 관리자 메뉴·지갑이 보이지 않음
- [ ] 난독화 빌드에서 크래시 없음 (로그인·녹음·친구 화면 한 바퀴)
- [ ] iOS: TestFlight 설치본에서 Apple 로그인 (개발 빌드와 권한이 다를 수 있음)
- [ ] Android: Play 내부 테스트 설치본에서 Google 로그인 (2.4)
